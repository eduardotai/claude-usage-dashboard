# Spec 001: Project Setup & Foundation

## Goal
Initialize the full project structure with working backend and frontend that can communicate.

## Acceptance Criteria
- [ ] SvelteKit frontend initialized with TypeScript + Tailwind
- [ ] FastAPI backend running with CORS enabled
- [ ] Basic health check endpoint working
- [ ] Frontend can fetch data from backend
- [ ] Clean folder structure following the PRD
- [ ] Dark theme basic layout in place

## Technical Notes
- Use port 8000 for backend
- Use port 5173 for frontend (Svelte default)
- Make log path detection flexible from the start
